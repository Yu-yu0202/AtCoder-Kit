# REVEL_SESSION の取得方法
AtCoder-Kit で AtCoder にログインする場合、ブラウザの `REVEL_SESSION` クッキーの値が必要です。

> [!IMPORTANT]
> `REVEL_SESSION` の取り扱いには十分注意してください。
>
> この値は、あなたの AtCoder アカウントの認証情報です。
> 
> 第三者に知られると、アカウントへ不正アクセスされる可能性があります。
> 
> SNS・GitHub・Issue・スクリーンショット等で誤って公開しないよう注意してください。

> [!NOTE]
> 取得した `REVEL_SESSION` は、AtCoder-Kit のログインセッション保存のためにのみ利用されます。
> 
> `atcoder.jp` 以外への外部送信や、不正アクセス用途での使用は行われません。

主要なブラウザでの取得方法は以下のとおりです。
## 1. Chromium ベースブラウザの場合（Chrome, Edge 等）
1. ログインをした状態で、AtCoder の任意のページを開きます。
2. ブラウザのデベロッパーツールを開きます（任意の箇所を右クリックして「検証」を選択するか、多くのOSでは `F12` キーを押します）。
3. 「Application」（「アプリケーション」）タブを選択します。
4. 左側のメニューから「Cookies」を展開し、`https://atcoder.jp` を選択します。
5. リストから「REVEL_SESSION」という名前のクッキーを探し、その「Value」（「値」）をコピーします。
6. コピーした値を AtCoder-Kit のログインプロンプトに貼り付けて、Enter キーを押します。

## 2. Firefox ベースブラウザの場合（Firefox, Floorp 等）
1. ログインをした状態で、AtCoder の任意のページを開きます。
2. ブラウザのデベロッパーツールを開きます（任意の箇所を右クリックして「検証」を選択するか、多くのOSでは `F12` キーを押します）。
3. 「Storage」（「ストレージ」）タブを選択します。
4. 左側のメニューから「Cookies」を展開し、`https://atcoder.jp` を選択します。
5. リストから「REVEL_SESSION」という名前のクッキーを探し、その「Value」（「値」）をコピーします。
6. コピーした値を AtCoder-Kit のログインプロンプトに貼り付けて、Enter キーを押します。
